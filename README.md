# Portfolio

A clean modern portfolio starter built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19 & TypeScript
- **Styling**: Tailwind CSS v4

---

## 📂 Project Structure

```text
src/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── components/
│   └── ui/
└── lib/
    └── utils.ts
```

---

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
